## Section 1 — Course Introduction

# Lecture 01: Introduction to NGINX

## Overview

This course is an **NGINX Masterclass and Certification Training** covering NGINX from basic concepts through advanced functionality.

The course is designed to accommodate both:

- Learners who already have some background with NGINX.
- Absolute beginners who have never worked with NGINX before.

The training begins with the fundamentals, including **NGINX installation**, and progressively moves toward advanced topics such as reverse proxying, load balancing, performance, security, caching, logging, compression, modular architecture, and cryptography.

The instructor is **Anshul Cholhan**, a DevOps professional with extensive knowledge of the DevOps toolset.

---

## Course Approach

The course is intentionally designed to be:

- **Modular** — topics are divided into separate sections.
- **Practical** — approximately **80% of the lectures are practical**.
- **Short and focused** — lectures are intended to be relatively short and to the point.
- **Beginner-friendly** — the course starts from the fundamentals rather than assuming extensive NGINX knowledge.

Some theory is included because understanding the underlying application and its fundamental concepts is necessary before working with NGINX practically.

The course is expected to contain approximately **12–15 sections**, progressing from basic to advanced NGINX topics.

---

# What You Will Learn

The course covers NGINX in several major roles and areas.

### 1. NGINX Fundamentals

The course starts with the fundamental concepts of NGINX on an **Ubuntu machine**, including installation and basic setup.

The goal is to start from the very beginning and progressively build the knowledge required to work with the NGINX toolset.

---

### 2. NGINX as a Web Server

NGINX will be explored as a **web server**, including how it can be configured and used to serve web content.

The course focuses on using NGINX as a web server rather than using it to configure an entire application stack.

---

### 3. NGINX as a Reverse Proxy

The course covers the **reverse proxy model** of NGINX and explains how this functionality differentiates NGINX from traditional web servers such as HTTPD.

The reverse proxy functionality is one of the major areas of the training.

---

### 4. NGINX as a Load Balancer

NGINX will also be used as a **software-based load balancer**.

The course demonstrates how to create and configure custom load-balancing functionality using the NGINX toolset.

---

## HTTP Protocol

Understanding the **HTTP protocol** is considered essential when working with NGINX.

This is particularly important because NGINX can be used to build:

- Web server configurations
- Web proxies
- Load balancers

The course therefore includes HTTP fundamentals before moving deeper into NGINX's HTTP-related functionality.

The training also covers **HTTP protocol compression** and how HTTP calls can be handled more efficiently with NGINX.

# Course Topics

The instructor outlines the major sections of the course as follows.

### 1. NGINX Introduction

The course begins by answering fundamental questions such as:

- What is NGINX?
- Why are we learning NGINX?
- What functionality does NGINX provide?

---

### 2. NGINX Installation

The installation section covers installing NGINX using:

- A **package manager**
- The **NGINX binary itself**

The course therefore introduces more than one approach to obtaining and installing NGINX.

---

### 3. HTTP Protocol

HTTP protocol knowledge is introduced as a prerequisite for understanding NGINX's web proxy and load-balancing capabilities.

---

### 4. NGINX Labs

Hands-on labs are used to practice working with NGINX.

The labs include practical work with HTTP-related functionality and demonstrate how to manage and create HTTP configurations in an NGINX lab environment.

---

### 5. NGINX Configuration Customization

The course explains how to customize the NGINX configuration and tune NGINX according to the requirements of an application.

The goal is not simply to use the default configuration, but to understand how NGINX can be adjusted for a particular application.

---

### 6. Performance and Security

The training covers:

- NGINX performance
- NGINX security

These topics are part of learning how to operate NGINX effectively in practical environments.

---

### 7. Reverse Proxy

The reverse proxy model is covered in detail.

The course also discusses how NGINX's reverse proxy functionality differs from other web servers, with **HTTPD** given as an example for comparison.

---

### 8. Load Balancing

The load-balancing section demonstrates how to create **custom software-based load balancers** using NGINX.

---

### 9. Cache Management

NGINX is also explored as a **cache management tool**.

The course explains how NGINX can help with **static content delivery**.

---

### 10. Static Assets

The training covers the management and handling of **static assets** with NGINX.

---

### 11. Access Management

The course includes **access management within NGINX**, covering how access can be managed through the NGINX configuration.

---

### 12. Logging and Monitoring

The training covers:

- NGINX logging management
- NGINX logging monitoring

These capabilities are important for understanding what is happening within an NGINX deployment and for operational management.

---

### 13. HTTP Compression

The course concludes the HTTP-focused portion by covering **HTTP compression** and how HTTP communication can be used more efficiently with NGINX.

---

### 14. Modular Architecture

The course then moves into the **modular architecture of NGINX**.

This section introduces how NGINX is structured around modules.

---

### 15. Latest NGINX Version

---

### 16. Cryptography

The course includes a dedicated topic on **cryptography** as part of the advanced NGINX material.

# Practical Scope of the Course

A key boundary of the training is that the course is focused specifically on NGINX functionality.

The instructor explicitly states that the course will **not** focus on configuring a complete website or database using NGINX.

Instead, the primary focus is:

- NGINX as a **web server**
- NGINX as a **load balancer**
- NGINX as a **reverse proxy**
- NGINX's associated configuration and operational capabilities

# Expected Learning Outcome

The course is designed so that learners can begin getting **hands-on experience with NGINX from the first day**.

By working through the practical lectures, learners should be able to:

- Apply their NGINX knowledge.
- Experiment with the NGINX toolset.
- Work directly with NGINX configurations.
- Think about how NGINX is being used within an existing system.
- Consider how an existing NGINX implementation could potentially be made more efficient.

For learners who already have applications using NGINX, the course encourages them to use the newly acquired knowledge to examine their current implementation and think about ways it could be improved.
